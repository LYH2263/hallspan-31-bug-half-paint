# HallSpan 考场间距排座

在考室网格上按最小曼哈顿距离排座，同试卷套不得四邻相邻，并输出违规与统计。

技术栈：Python 3.12 / FastAPI / SQLAlchemy / PostgreSQL / Vue 3 / TypeScript / Vite

## 左右半场两本账

考室按**分界列**切成左右两个半场，左右各写一本独立占用账：

- 提交排座（`POST /api/seating/run`）瞬间分界列切开两本账，两账各自独立放置、
  各自记账（双写）；不是先排一张总图再按列涂色。
- 考生可标记左账 `L` / 右账 `R`（`PUT /api/candidates/{id}`）；已标记的人只进
  自己那本账，禁止为凑均衡记进对面账。未标记的人在该次提交里归入且只归入一本账。
- 排座图、左账人数、右账人数、统计同一套，都由两本账导出。
- 合账已座人数之差大于 1 且无法在账内消化 → 整场失败，不增方案。
- 半场座位不足与间距不足是两条独立消息，不并句。
- 改分界列（`PUT /api/halls/{id}`）或改标记后，两本账与最新方案同成功或同失败；
  历史方案不回刷。分界列越界（不在 `1..cols-1`）拒绝保存，两本账与最新方案不动。

## 启动

```bash
docker compose up --build
```

| 服务 | 地址 |
| --- | --- |
| 前端 | http://localhost:4900 |
| API | http://localhost:9900 |
| API 文档 | http://localhost:9900/docs |
| Postgres | localhost:5450 |

健康检查：`GET http://localhost:9900/api/health`

## 使用说明

1. 在「考室」「考生」「试卷套」确认基础数据，必要时调整分界列与左右标记。
2. 打开「排座图」执行间距排座，查看左右两本账与分界线。
3. 在「违规」查看间距或同卷相邻问题。
4. 在「统计」查看占用、左右账人数与违规汇总。
